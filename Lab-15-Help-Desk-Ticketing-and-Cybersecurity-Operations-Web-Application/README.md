# Lab 15 - Help Desk Ticketing and Cybersecurity Operations Web Application

## Overview
This lab demonstrates the creation of a modern IT support and cybersecurity operations web application using AI assisted development tools. The objective was to simulate a real world enterprise help desk environment where technicians can manage support tickets, monitor security alerts, and perform Active Directory style account management tasks.

The project combines concepts from IT support, system administration, ticket management, and cybersecurity monitoring into a single web application portfolio project. The application was designed to resemble an internal IT operations dashboard used within a corporate environment.

## Tasks Performed

1. Created a new Replit web application project
2. Designed a landing page for the IT operations platform
3. Built a login interface with technician and administrator roles
4. Created a help desk dashboard displaying ticket statistics
5. Developed a ticket submission form for end users
6. Added ticket workflow statuses including:
   - Open
   - In Progress
   - Escalated
   - Resolved
7. Created a simulated Active Directory management panel
8. Added user account actions including:
   - Password reset
   - Account unlock
   - Enable account
   - Disable account
9. Implemented cybersecurity monitoring widgets
10. Added simulated alerts for:
    - Failed login attempts
    - Firewall alerts
    - Endpoint monitoring
11. Integrated analytics charts for ticket activity
12. Tested application responsiveness and functionality
13. Uploaded the completed project to GitHub
